# Фотоателье — Django-проект (backend)

## 1. Назначение

Веб-сервис для управления заказами фотоателье. Предназначен для
сотрудников (приём и обработка заказов) и клиентов (через Flutter-
приложение).

Основные функции:
- учёт клиентов, сотрудников, услуг и заказов;
- приём заказов через API (Flutter) и веб-интерфейс сотрудника;
- отслеживание статуса, история изменений;
- уведомления клиентов;
- отчёт по заказам за период.

## 2. Роли

| Роль | Описание |
|---|---|
| **Суперпользователь** | Полный доступ к Django Admin. Роль `administrator`. |
| **Администратор** | Управляет справочниками (услуги, категории, форматы),
  видит заказы, создаёт учётные записи. |
| **Сотрудник** | Обрабатывает заказы через собственный интерфейс.
  Не имеет доступа к Django Admin. |
| **Клиент** | Регистрируется в Flutter-приложении, создаёт и
  изменяет новые заказы через API. |

Роли назначаются через Django Admin (поле «Роль» в карточке пользователя).

## 3. Требования

- Python 3.14
- Виртуальное окружение `.venv`
- Зависимости из `requirements.txt`:

  ```
  asgiref==3.12.1
  Django==5.2.17
  django-cors-headers==4.9.0
  sqlparse==0.6.0
  tzdata==2026.4
  ```

## 4. Первый запуск (PowerShell, из корня `backend`)

```powershell
py -3.14 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe manage.py migrate
.\.venv\Scripts\python.exe manage.py createsuperuser
.\.venv\Scripts\python.exe manage.py setup_roles
.\.venv\Scripts\python.exe manage.py runserver
```

## 5. Адреса

| Адрес | Описание |
|---|---|
| `http://127.0.0.1:8000/` | Веб-интерфейс сотрудника (заказы) |
| `http://127.0.0.1:8000/admin/` | Django Admin (справочники) |
| `http://127.0.0.1:8000/reports/` | Отчёт по заказам |
| `http://127.0.0.1:8000/api/...` | REST API (Flutter) |

## 6. Начальная настройка

После первого запуска через Django Admin создайте:
1. хотя бы одну **категорию**;
2. хотя бы один **формат услуги**;
3. **доступную услугу** (is_active = Да).

Клиенты регистрируются в отдельном Flutter-приложении.

## 7. Повторный запуск

```powershell
.\.venv\Scripts\python.exe manage.py runserver
```

Используйте интерпретатор из `.venv`.

## 8. База данных

Рабочая база `db.sqlite3` в репозиторий не включена.
Создаётся автоматически при `migrate`.
Django и Flutter могут работать одновременно.
